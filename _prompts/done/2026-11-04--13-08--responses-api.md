# Переход проверочного чата на Responses API

## Суть

### Проблема

Проверочный чат должен поддерживать современные модели и сохранять связность разговора при вызове инструментов.
История не должна терять результаты действий при сокращении длинного разговора.

### Решение

Выделить обращение к модели, сохранить выполнение инструментов на нашем сервере и использовать общую обработку
ответов. Подходящие части соседнего проекта использовать как образец, без переноса его внутренних зависимостей.
